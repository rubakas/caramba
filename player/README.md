# @jellyfin-rails/player

Embeddable web video player extracted from jellyfin-web. Pairs with the
[`jellyfin-rails`](../../README.md) Ruby gem but talks plain HLS so any backend
can serve it.

> **Status:** Phase 0 skeleton. Real player lands in phase 3.
